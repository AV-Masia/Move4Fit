# 02. Функциональный опросник и логика подбора

## Функциональный опросник — 5 навыков

Вопросы описывают возможности ребёнка. **Помощь и опора — не неудача, а параметр
выбора безопасного варианта.**

1. **Сидение** — Может ли ребёнок безопасно сидеть на стуле с опорой на стопы?
   Варианты: самостоятельно; с дополнительной опорой/поддержкой; не может безопасно сидеть на обычном стуле.
2. **Вставание** — Может ли ребёнок безопасно встать из положения сидя?
   Варианты: самостоятельно; с опорой/поддержкой; не может безопасно перейти в положение стоя.
3. **Стояние** — Может ли ребёнок безопасно удерживать положение стоя?
   Варианты: самостоятельно; с опорой/поддержкой; небезопасно; только в вертикализаторе.
4. **Ходьба / перемещение** — Как ребёнок обычно перемещается?
   Варианты: ходит самостоятельно; ходит с опорой; активная коляска; электрическая коляска.
5. **Перемещение на пол и с пола** — Может ли ребёнок безопасно переместиться на пол
   и вернуться на стул/кровать?
   Варианты: самостоятельно; с поддержкой; не может безопасно выполнить переход.

## Логика подбора упражнений

- Учитываем **полную картину ответов**, а не один ответ.
- Определяем безопасные исходные положения и доступные переходы.
- Выбираем упражнения на силу с подходящим уровнем опоры.
- Видео показывает технику и варианты поддержки.
- Если переход на пол небезопасен — не предлагаем упражнения, требующие его.
- При слишком сложном варианте возвращаемся к более простому.

Короткая формулировка (блок «Логика подбора упражнений»):
1. Подбор строится по полной картине ответов на все пять навыков, а не «один ответ — одно упражнение».
2. Сначала определяем, какие исходные положения и переходы ребёнок может выполнять безопасно.
3. Затем из библиотеки выбираем упражнения на силу, доступные в этих положениях и с подходящим уровнем опоры.
4. Видео показывает технику и возможные варианты поддержки; не нужно заранее описывать в таблице все клинические варианты помощи.
5. Если ребёнок не может безопасно перейти на пол и обратно — исключаем упражнения, требующие такого перехода, но не исключаем автоматически все упражнения на полу, если можно организовать безопасный доступ.

## Блок-схема подбора по навыкам

Дерево решений: **Навык → выбранное утверждение → какие упражнения предлагаем.**

### Навык 1. Сидение на стуле с опорой на стопы

| Утверждение | Предлагаем |
|---|---|
| Может сидеть на стуле с опорой на стопы **самостоятельно** | Упражнения в положении сидя на стуле **без опоры** |
| Для удержания сидя требуется **дополнительная опора/поддержка** | Упражнения сидя на стуле с опорой на ноги и с опорой на стол |
| **Не может** удерживать положение сидя безопасно (требуется специальный стул с поддержками) | Упражнения в специальном стуле и упражнения в кровати |

### Навык 2. Вставание из положения сидя (с опорой на ноги)

| Утверждение | Предлагаем |
|---|---|
| Может встать **самостоятельно** | Упражнение «сесть-встать» без опоры |
| Требуется **дополнительная опора/поддержка**, чтобы встать | «Сесть-встать» с опорой перед человеком |
| **Не может** безопасно перейти в положение стоя | Пересаживания по кровати; привставание со стула; пересаживание со стула на стул |

### Навык 3. Перемещение

| Утверждение | Предлагаем |
|---|---|
| Ходит **самостоятельно** | Упражнения стоя без опоры, переминания без опоры, замахивания без опоры 📝 |
| Ходит **с опорой/поддержкой** | Упражнения стоя с опорой и с переходом в положение стоя с опорой (приседания с опорой, подъём на ступеньку с опорой, переминания с опорой) |
| Перемещается на **активной коляске** | Упражнения сидя (привставания с помощью, пересаживания, переминания сидя, подъём на ступеньку сидя) |
| Перемещается на **электроколяске** | Упражнения сидя, упражнения с поддержкой, упражнения в кровати |

### Навык 4. Удержание положения стоя

| Утверждение | Предлагаем |
|---|---|
| Может стоять **самостоятельно** | Упражнения стоя и с переходом в положение стоя (приседания без опоры, подъём на ступеньку с опорой и без, переминания) |
| Требуется **дополнительная опора/поддержка** для удержания позы стоя | Упражнения стоя с опорой и с переходом в положение стоя с опорой (приседания с опорой, подъём на ступеньку с опорой, переминания с опорой) |
| **Не может** безопасно удерживать положение стоя даже с опорой | Упражнения сидя (привставания с помощью, пересаживания, переминания сидя, подъём на ступеньку сидя) |
| Может удерживать положение стоя **только в вертикализаторе** | Упражнения стоя в вертикализаторе (сталкивать тяжёлые мячи или мешки со стола) |

### Навык 5. Перемещение на пол и с пола

| Утверждение | Предлагаем |
|---|---|
| Может **самостоятельно** переместиться на пол и обратно на стул/кровать | Упражнения на полу |
| Может переместиться на пол **с поддержкой** и обратно | Упражнения на полу и альтернатива в кровати |
| **Не может** безопасно переместиться на пол и обратно | Упражнения на/в кровати |
