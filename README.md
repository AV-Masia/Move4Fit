# Move4Fit — MVP

Домашние занятия для детей с особенностями развития (ДЦП и др.). Родитель отвечает на простые вопросы о том,
что ребёнок умеет, и о запретах врача; приложение определяет внутренний функциональный уровень (по мотивам
GMFCS I–V) и каждый день предлагает одно рекомендованное занятие, постепенно усложняя упражнения.

**Диагноз в приложении не спрашивается и не хранится.** Профиль ребёнка — это имя, возраст, ограничения и
противопоказания и функциональные возможности: тест движений из 5 пунктов и, если врач его называл, уровень GMFCS.

> ⚠️ **Медицинская логика — черновик.** Тест из 5 пунктов, правила определения уровня, ограничения и
> противопоказания, упражнения и правила прогрессии написаны для проверки работы алгоритма. Перед запуском их должен
> проверить и утвердить квалифицированный специалист (врач ЛФК / реабилитолог). Все такие места в коде помечены
> `⚠️ ЧЕРНОВИК`.

## Запуск

Нужен Node.js 20+.

```bash
npm install
npm start          # затем открыть в Expo Go на телефоне (QR-код) или нажать w для браузера
npm run web        # сразу в браузере: http://localhost:8081
npm test           # тесты алгоритма
npm run typecheck
npm run review-doc # пересобрать docs/na-proverku-specialistu.md — документ для врача
```

## Стек

- **Expo (React Native) + TypeScript** — одно приложение для iOS, Android и веба.
- **Expo Router** — навигация по файлам в `app/`.
- **expo-video** — видео упражнений.
- **AsyncStorage** — пока все данные хранятся на телефоне.
- **Vitest** — тесты доменной логики.

## Алгоритм

```
возраст → ограничения и противопоказания → функциональные возможности (тест из 5 пунктов, GMFCS) →
функциональный уровень → подходящие упражнения → уровень сложности → прогрессия
```

1. **Тест движений из 5 пунктов.** Голова и сидение, стояние, ходьба, лестница, бег и прыжки. В каждом пункте
   родитель выбирает самое сложное, что ребёнок обычно делает сам. Пункт задаётся, только если предыдущая ступень
   пройдена (не спрашиваем про лестницу, если ребёнок не стоит).
2. **Возможности.** Выбранные варианты превращаются в набор возможностей: `sit_independent`, `walk_with_device`, …
3. **Уровень 1–5.** Родитель видит группу: «Активный», «Ходит самостоятельно», «Ходит с опорой», «Сидит»,
   «Нужна поддержка». Если врач называл уровень GMFCS, родитель может его указать (необязательно, уровни подписаны
   словами). Тогда берётся более осторожный уровень из двух; уровень от врача не может сделать занятия сложнее,
   чем по тесту. При расхождении на 2 ступени и больше родителя просят перепроверить ответы.
4. **Ограничения и противопоказания.** 10 вопросов (судороги, недавняя операция, тазобедренный сустав, шунт,
   запрет на кувырки и наклоны вниз головой, запрет на прыжки, другие запреты врача…). Ответ «да» исключает
   упражнения с определёнными рисками. У двух вопросов о запретах врача есть ответ «Не знаю» — упражнения
   исключаются так же, как при «да», пока родитель не уточнит. Судороги без контроля, операция за 6 месяцев,
   болезни сердца и «другие запреты врача» закрывают занятия до подтверждения разрешения врача.
5. **Подбор.** Упражнение подходит, если совпадает уровень, возраст ≥ минимального, есть все нужные возможности
   и нет исключённых рисков.
6. **Тренировка дня.** Разминка + 3 основных + заминка. Сначала берутся упражнения, которые давно не делали, и
   разные цели (сила, равновесие, координация…). Неделя: цель 3 занятия, не чаще раза в день, после занятия —
   предложение отдохнуть.
7. **Прогрессия.** У каждого упражнения 3 уровня сложности. 2 раза подряд «легко» → сложнее; «тяжело» → проще;
   боль → проще и совет написать куратору. Если всё на максимуме и легко — предложение пройти анкету заново.
8. **Безопасность.** Перед первым занятием родитель читает и принимает правила. Перед каждым занятием — вопрос,
   не устал ли ребёнок. После отметки о боли занятия ставятся на паузу, пока родитель не подтвердит, что ребёнку
   лучше. Если при повторной анкете появилась новая особенность, требующая разрешения врача, оно спрашивается заново.
   Пропущенные упражнения не влияют на прогрессию и предлагаются в следующий раз.
9. **Цель семьи.** Родитель выбирает цель на 2–3 месяца (или пишет свою); через 8 недель оценивает продвижение
   по пяти ступеням. На подбор упражнений цель пока не влияет — это следующий шаг, нужен список от специалиста.
10. **Отзыв и перерывы.** Общий отзыв о занятии можно уточнить по отдельным упражнениям. Боль отмечается через
    наблюдаемые признаки. После перерыва больше недели приложение спрашивает причину и при необходимости снижает
    нагрузку.
11. **Значки и путь.** Значки даются за регулярность и заботу («Первый шаг», «Подвижный ребёнок», «Супермама» /
    «Суперпапа»…), а не за результат ребёнка. «Наш путь»: дней с первого занятия, упражнений, примерное время.
    Шкала динамики сравнивает первый и последний результат тестов. Баллов и рейтингов нет.
12. **Динамика.** 1–2 теста по уровню (вставания со стула за 30 с, стояние на одной ноге, удержание сидя,
   удержание головы).
